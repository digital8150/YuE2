# YuE2 Studio

Oracle 서버 및 GPU 워커 운영 방법: [DEPLOYMENT.md](DEPLOYMENT.md)

YuE2 Studio는 승인된 동아리원이 음악을 만들고 결과를 공유하는 웹앱입니다.
Python `aiohttp` 서버가 ComfyUI와 SQLite를 연결하고, 브라우저 화면은 HTML/CSS/JavaScript로 동작합니다.
각 회원의 작업은 내 스튜디오에 보관되고, 선택해 공개한 곡만 공용 라이브러리에 나타납니다.

## 시작하기

1. 저장소 루트에서 `run_yue2_studio.bat`를 실행합니다. 바탕화면 바로가기처럼
   다른 현재 폴더에서 실행해도 됩니다.
2. 잠시 후 [http://127.0.0.1:7860](http://127.0.0.1:7860)을 엽니다. 첫 실행이라면
   서버 창에 표시된 **최초 관리자 설정 코드**를 화면에 입력하고 관리자 계정을 만드세요.
   설정 코드는 관리자 계정을 만든 뒤 사용할 수 없습니다. ComfyUI가
   실행 중인지 확인하려면 [http://127.0.0.1:8188](http://127.0.0.1:8188)을
   사용할 수 있습니다.
3. 동아리원은 `계정 신청하기`에서 계정을 만들고, 관리자는 왼쪽 프로필의 `가입 승인`에서 승인합니다.
   승인 전에는 작업, 음악, 다운로드 API에 접근할 수 없습니다.
4. 새 곡 모드에서는 스타일과 가사만으로 바로 생성합니다. 커버 모드에서는 참고
   오디오를 함께 선택합니다. 길이, 시드, 샘플링 값은 `고급 옵션`에서 조정할 수
   있습니다.

화면은 다크 테마의 메뉴·편집기·작업 공간으로 구성됩니다. 내 스튜디오 작업 목록은 제목,
스타일, 상태로 찾아볼 수 있고, 대기열 PIP 위젯 및 전용 페이지에서 내 작업 진행 상황과
GPU 엔진 상태를 확인할 수 있습니다. 라이브러리에서는 곡·앨범·아티스트 페이지와 차트를 탐색합니다.
하단 플레이어는 화면을 이동해도 유지되며 이전/다음 곡,
재생 위치, 볼륨을 조절할 수 있습니다. 모바일에서는 세로 편집기와 2열 라이브러리로 전환됩니다.

완료된 곡의 `라이브러리에 공개`에서 아티스트·제목·표지와 싱글/앨범을 지정합니다.
`아티스트 백오피스`에서 한 계정으로 여러 가상명의 아티스트를 만들고 각 프로필과 앨범을 관리합니다.
라이브러리 화면은 공개 음악 탐색과 감상에 사용합니다.
공개 곡의 `내 스튜디오로 가져오기`는 MP3의 ComfyUI 프롬프트 메타데이터에서 스타일·가사·시드·옵션을 읽습니다.
자세한 사용법은 [README_STUDIO.md](README_STUDIO.md)를 참고하세요.

라이브러리 정보와 업로드한 이미지는 `yue2_app/data/`에, 생성된 오디오는 `ComfyUI/output/yue2/`에
저장됩니다. 서버를 다시 시작해도 목록과 결과 파일이 유지됩니다. 백업할 때는 두
디렉터리를 함께 보관하세요.

## 동아리원에게 공유

- 같은 신뢰할 수 있는 LAN에서 쓴다면 `run_yue2_studio_lan.bat`를 실행하고 호스트 PC의
  `http://<호스트-LAN-IP>:7860` 주소를 알려주세요. Windows 방화벽에서 7860/TCP 접근도 허용해야 합니다.
  ComfyUI의 8188 포트는 localhost에만 두세요.
- 외부 인터넷에서 접속시킬 때는 도메인과 HTTPS 역방향 프록시를 마련하고 Studio의
  7860 포트만 프록시하세요. 이때 `YUE2_SECURE_COOKIES=1`과
  `YUE2_PUBLIC_ORIGIN=https://studio.example.org`(실제 공개 주소)를 설정해야 합니다.
  로그인 쿠키는 HTTPS에서만 전송됩니다. HTTP 주소를 인터넷에 직접 공개하지 마세요.
- 서버를 옮길 때 `yue2_app/data/yue2.sqlite3`과 `ComfyUI/output/yue2/`를 함께 옮기면
  계정, 승인 상태, 작업, 음악이 유지됩니다. 이전에 만든 작업은 `이전 작업`으로 표시됩니다.
- 서버 환경 변수 `YUE2_HOST`(기본 `127.0.0.1`), `YUE2_PORT`(기본 `7860`),
  `YUE2_SETUP_TOKEN`(최초 관리자 설정 코드 지정)을 사용할 수 있습니다.

## 문제 해결

- **엔진 오프라인**: ComfyUI 창이 열렸는지, 모델 파일과 Python 가상환경이
  준비됐는지 확인한 뒤 래퍼를 다시 실행합니다. 포트 8188이 이미 사용 중이면
  해당 프로그램을 종료하거나 ComfyUI 설정을 정리한 후 다시 시도하세요.
- **스튜디오 포트 충돌**: 7860을 사용 중인 프로세스를 종료한 뒤 다시 실행합니다.
  8188은 ComfyUI용이고 7860은 Studio용입니다.
- 실행 로그가 필요하면 실행한 배치 창을 닫지 말고 오류 메시지를 확인하세요.

## 테스트

```text
venv\Scripts\python.exe -m unittest discover -s tests -v
```

샘플 곡과 무음 오디오로 UI를 확인하려면 `venv\Scripts\python.exe tests\ui_preview.py`를
실행하고 `http://127.0.0.1:7861`을 엽니다. 테스트 서버는 메모리에서만 동작하며
실제 라이브러리나 생성 엔진에 접근하지 않습니다.
