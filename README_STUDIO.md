# YuE2 Studio

YuE2 Studio는 승인된 동아리원이 음악을 만들고 결과를 공유하는 웹앱입니다.
Python `aiohttp` 서버가 ComfyUI와 SQLite를 연결하고, 브라우저 화면은 HTML/CSS/JavaScript로 동작합니다.
각 회원의 생성 작업은 내 스튜디오에 보관됩니다. 라이브러리에는 창작자가 선택해 공개한 음악만 나타납니다.

## 시작하기

1. 저장소 루트에서 `run_yue2_studio.bat`를 실행합니다. 바탕화면 바로가기처럼
   다른 현재 폴더에서 실행해도 됩니다.
2. 잠시 후 [http://127.0.0.1:7860](http://127.0.0.1:7860)을 엽니다. 첫 실행이라면
   서버 창에 표시된 **최초 관리자 설정 코드**를 화면에 입력하고 관리자 계정을 만드세요.
   설정 코드는 관리자 계정을 만든 뒤 사용할 수 없습니다. ComfyUI가
   실행 중인지 확인하려면 [http://127.0.0.1:8188](http://127.0.0.1:8188)을
   사용할 수 있습니다.
3. 동아리원은 `계정 신청하기`에서 계정을 만들고, 관리자는 왼쪽 프로필의 `가입 승인`에서 승인합니다.
   승인 전에는 작업, 음악, 다운로드 API에 접근할 수 없습니다.
4. 새 곡 모드에서는 스타일과 가사만으로 바로 생성합니다. 커버 모드에서는 참고
   오디오를 함께 선택합니다. 길이, 시드, 샘플링 값은 `고급 옵션`에서 조정할 수
   있습니다.

## 기기 내 AI로 프롬프트 초안 만들기

편집기 상단의 `아이디어로 프롬프트 만들기`에 원하는 곡을 한국어 또는 영어로 적고
가사 언어를 선택한 뒤 `초안 만들기`를 누르세요. 초안을 확인하고 `편집기에 적용`을
누르면 곡 제목, YuE2 스타일과 가사가 편집기에 들어갑니다. 음악 생성은 별도로 눌러야 합니다.
연주곡 스위치를 켜면 가사 없이 스타일만 만듭니다. 커버 모드에서는 참고 오디오의
내용을 AI가 분석하지 않으므로 원하는 새 편곡 방향을 아이디어에 직접 적어주세요.

이 기능은 Chrome의 [Prompt API](https://developer.chrome.com/docs/ai/prompt-api)와
[Translator API](https://developer.chrome.com/docs/ai/translator-api)를 브라우저 안에서
사용합니다. Prompt API의 한국어 입력과 출력은 아직 지원되지 않아 한국어 아이디어는
영어로 번역한 뒤 처리하고, 한국어를 선택하면 생성된 영어 제목과 가사를 다시
번역합니다. 번역된 제목과 가사는 직접 검토하세요. 일부 줄의 번역 결과가
비면 그 줄은 원문으로 남기고 화면에 건수를 표시합니다. 모델과 번역 언어팩은 첫
사용 시 내려받을 수 있습니다. Chrome 데스크톱의 기기 요구 사항을 충족해야 하며,
지원하지 않는 기기에서는 기존 스타일·가사 수동 입력을 계속 사용할 수 있습니다.
브라우저 AI API는 보안 출처에서만 제공되므로 로컬 `localhost` 또는 HTTPS로
접속하세요. `http://<호스트-LAN-IP>` 접속에서는 이 기능이 비활성화될 수 있습니다.
이 초안 생성 과정에서 아이디어를 Studio 서버로 보내지 않습니다. 음악 생성을 누르면
적용된 제목, 스타일과 가사는 기존 생성 요청으로 전송됩니다.

AI 지시문은 YuE2 [공식 생성 가이드](https://github.com/multimodal-art-projection/YuE/blob/main/docs/generation.md)의
문법을 따릅니다. `title`에는 짧은 곡 이름을, `style`에는 언어, 장르, 보컬, 템포, 악기 등을 쓰고 `lyrics`에는
`[Verse]`, `[Chorus]` 같은 구간 태그와 실제 노랫말만 넣습니다. 앱은 초안을
적용하기 전에 제목, 스타일과 가사의 형식과 길이를 확인합니다.

화면은 다크 테마의 메뉴·편집기·작업 공간으로 구성됩니다. 내 스튜디오 작업 목록은 제목,
스타일, 상태로 찾아볼 수 있고, 대기열 PIP 위젯 및 전용 페이지에서 내 작업의 진행 상황과
GPU 엔진 상태를 확인할 수 있습니다. 하단 플레이어는 화면을 이동해도 유지되며 이전/다음 곡,
재생 위치, 볼륨을 조절할 수 있습니다.

## 라이브러리와 아티스트 페이지

1. 생성된 곡은 우선 **내 스튜디오**에만 남습니다. 완료된 곡의 `라이브러리에 공개`를 눌러
   공개 제목과 앨범 표지를 확인하세요. 공개 창에서 아티스트와 **싱글** 또는 해당 아티스트의 앨범을 고른 뒤 공개합니다.
   같은 창에서 공개 정보를 다시 수정할 수 있고, `공개 취소`로 라이브러리에서 내릴 수 있습니다.
2. 별도 `아티스트 백오피스` 페이지에서 한 계정으로 여러 가상명의 아티스트를 만들고 각각 이름·소개·프로필 이미지·
   배너를 설정합니다. 아티스트별 앨범 제목·소개·표지도 백오피스에서 관리합니다. 공개 창에서는
   아티스트를 먼저 고른 뒤 해당 아티스트의 앨범을 선택합니다. 앨범에 첫 곡이 공개되면 앨범 페이지가 나타납니다.
3. `둘러보기`는 새 음악·인기 곡·신곡·앨범·아티스트를 보여줍니다. `차트`는 공개 곡의 재생
   시작 횟수로 정렬합니다. 아티스트·앨범·싱글 페이지와 `모든 음악`에서 곡을 탐색합니다.
4. 공개 곡의 `내 스튜디오로 가져오기`는 MP3에 ComfyUI가 저장한 `prompt` 메타데이터를 읽어
   스타일·가사·시드·생성 옵션을 편집기에 채웁니다. 커버 곡은 원본 참고 오디오를 다시
   선택해야 합니다. MP3에 프롬프트 메타데이터가 없다면 가져올 수 없습니다.

앨범·아티스트·싱글 주소는 URL 해시로 공유할 수 있습니다. 공유받은 사람도 승인된 계정으로
로그인해야 음악을 들을 수 있습니다. 개인 작업의 오디오와 설정은 공개 전 다른 회원에게 제공되지 않습니다.

라이브러리 정보와 업로드한 표지·프로필 이미지는 `yue2_app/data/`에, 생성된 오디오는 `ComfyUI/output/yue2/`에
저장됩니다. 서버를 다시 시작해도 목록과 결과 파일이 유지됩니다. 백업할 때는 두
디렉터리를 함께 보관하세요.

## 동아리원에게 공유

- 같은 신뢰할 수 있는 LAN에서 쓴다면 `run_yue2_studio_lan.bat`를 실행하고 호스트 PC의
  `http://<호스트-LAN-IP>:7860` 주소를 알려주세요. Windows 방화벽에서 7860/TCP 접근도 허용해야 합니다.
  ComfyUI의 8188 포트는 localhost에만 두세요.
- 외부 인터넷에서 접속시킬 때는 도메인과 HTTPS 역방향 프록시를 마련하고 Studio의
  7860 포트만 프록시하세요. 이때 `YUE2_SECURE_COOKIES=1`과
  `YUE2_PUBLIC_ORIGIN=https://studio.example.org`(실제 공개 주소)를 설정해야 합니다.
  로그인 쿠키는 HTTPS에서만 전송됩니다. HTTP 주소를 인터넷에 직접 공개하지 마세요.
- 서버를 옮길 때 `yue2_app/data/yue2.sqlite3`과 `ComfyUI/output/yue2/`를 함께 옮기면
  계정, 승인 상태, 작업, 음악이 유지됩니다. 이전에 만든 작업은 `이전 작업`으로 표시됩니다.
- 서버 환경 변수 `YUE2_HOST`(기본 `127.0.0.1`), `YUE2_PORT`(기본 `7860`),
  `YUE2_SETUP_TOKEN`(최초 관리자 설정 코드 지정)을 사용할 수 있습니다.

## 문제 해결

- **엔진 오프라인**: ComfyUI 창이 열렸는지, 모델 파일과 Python 가상환경이
  준비됐는지 확인한 뒤 래퍼를 다시 실행합니다. 포트 8188이 이미 사용 중이면
  해당 프로그램을 종료하거나 ComfyUI 설정을 정리한 후 다시 시도하세요.
- **스튜디오 포트 충돌**: 7860을 사용 중인 프로세스를 종료한 뒤 다시 실행합니다.
  8188은 ComfyUI용이고 7860은 Studio용입니다.
- 실행 로그가 필요하면 실행한 배치 창을 닫지 말고 오류 메시지를 확인하세요.

## 테스트

```text
venv\Scripts\python.exe -m unittest discover -s tests -v
node --test tests/test_prompt_assistant.cjs
```

샘플 곡과 무음 오디오로 UI를 확인하려면 `venv\Scripts\python.exe tests\ui_preview.py`를
실행하고 `http://127.0.0.1:7861`을 엽니다. 테스트 서버는 메모리에서만 동작하며
실제 라이브러리나 생성 엔진에 접근하지 않습니다.
